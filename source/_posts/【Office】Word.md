# 公式编号及引用

编号：

1. `alt+fn+f9`进入域代码模式

2. 在章节标题处`ctrl+fn+f9`输入域代码的大括号（shift是切换当前域代码），插入如下

   ```
   { SEQ seq \h}{ SEQ eq \r \h}
   ```

   - `SEQ` 是关键词
   - `seq` 是变量名字，可以是其他的，比如chart等
   - `\h` 表示隐藏域的结果
   - `\r`自此之后重置序号计数器为1 

3. 复制2中的代码到每一个章节的标题后面

4. 公式编号：输入完公式后输入`#({ SEQ seq \c}-{ SEQ eq })`，再回车。连接符号是`-`，也可以是`.`等自定义

5. `alt+fn+f9`退出域代码模式

6. `alt+shift+u`更新域代码，或者直接打印预览一下

引用：

1. 选中公式编号，插入书签，输入名称
2. 引用的时候用交叉引用就可以了



# 在字符上或者下加符号

```
{eq \o(\s\up1(\o(\s\up3(←),\s\do3(←),—)))}
```

- `{EQ ... }`：域的“公式”类型声明，告诉Word这里要插入的是一个数学公式或特殊排版结构。
- `\o()`：重叠函数。它将括号内用逗号分隔的多个元素，从上到下重叠在一起。
  - 规则：第一个元素在最上层，最后一个元素在最底层。

- `\s`：表示开始一个上下标位置的元素。
- `\up3`：表示将这个元素向上移动 `1` 磅。这个数字可以调整，值越大，元素的位置越高。

```
{EQ \* jc0 \* "Font:Times New Roman" \* hps20 \o(\s\up 11(•••••),Pu)}
```

- `\* jc0`：设置对齐方式。`jc0` 表示居左对齐，`jc1` 表示居中，`jc2` 表示居右。这里可能受文档整体格式影响。

- `\* "Font:Times New Roman"`：强制将域内的所有字符（包括点号和字母）的字体设置为 **Times New Roman**。这确保了显示效果的一致性。
- `\* hps20`：设置字体大小。`hps` 后面跟的数字代表半磅值。`hps20` 表示将字体大小设置为 `10` 磅（因为 20 / 2 = 10）。
